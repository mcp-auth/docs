# 类型别名：AuthorizationServerMetadata

```ts
type AuthorizationServerMetadata = z.infer<typeof authorizationServerMetadataSchema>;
```

OAuth 2.0 授权服务器元数据 (Authorization Server Metadata) 的模式，定义见 RFC 8414。
